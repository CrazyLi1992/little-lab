02 / 手动指令

参数填写说明

字段名保持英文；字符串用双引号，整数不加引号，字段之间用逗号。说明用于正常填参，仍可在编辑器构造异常值。修改参数后请点击“生成新 ID 报文”，再发送下方报文。

报文各字段是什么意思？
action · 指令名称
英文协议标识，与所选模板对应；中文名称仅用于显示。
id · 消息编号
“生成新 ID 报文”自动生成新编号，用于关联回复。测试重复命令时可原样重发。
sn · 目标序列号
来自上方连接配置，指明本次命令的目标。
params · 指令参数
填写本指令的 JSON 对象；无参数时保留 {}。编辑器中的原始报文是实际发送内容。

发送不附加换行、不保留消息；QoS 1。模板中的 $utc 在生成或执行时替换为当前 UTC 秒。

03 / 上报与 ACK

等待 post…

ACK 使用 postResponse，复制所选 post 的 id、sn 和 report_type（上报类型：realtime 为实时，non_realtime 为非实时）；status 是你发送的确认值，不是工具的测试结论。自动 ACK 默认关闭。修改开关、状态或延时会取消待发 ACK；断开也会取消。可在编辑器改 ID、report_type 等字段后手动发送。

04 / 自动指令序列

未运行

序列格式与 AI 操作说明

send：action、params、可选 id（$last 复用上一 ID）、waitReply、timeoutMs、onTimeout（stop/continue）。raw 字符串可直接发送异常内容。delay：ms。waitPost：timeoutMs。checkpoint：message，等待点击继续。回复仅按 action + id + sn 关联，不检查 status。未指定时回复等待 10 秒，超时停止；内置模板显式设置 continue 以便继续收集记录，可修改为 stop。不会自动退出 CMD 或恢复配置。序列可能修改设备设置，请检查后运行。

AI 可通过此页面选择模板、编辑 JSON、点击运行/暂停/继续/停止、读取或导出日志。所有操作均使用可见表单，无需执行脚本。当前页关闭或刷新会停止运行；后台标签页的计时可能延后。
